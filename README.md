# نظام تسجيل الزيارات — Dawaa Al Hayat

بديل بوت تلغرام على n8n: تطبيق ويب + لوحة إدارة + تطبيقات أندرويد و iOS
لتسجيل زيارات المندوبين للأطباء والصيدليات.

---

## البنية

```
apps/
├── api/      NestJS + Prisma + PostgreSQL      ← منطق العمل كله هنا
├── web/      Next.js — الموقع والتطبيق والأدمن
└── mobile/   Flutter — Android + iOS بكود واحد

infra/        docker-compose + نسخ احتياطي
scripts/      استيراد وتحليل البيانات
data/         ملفات المصدر والمخرجات  (مستثناة من git)
```

**قاعدة البيانات:** 31 جدولاً · 48 فهرساً · PostgreSQL 16 + `pg_trgm` + `unaccent`

## قرارات التصميم المهمة

| القرار | التنفيذ | السبب |
|---|---|---|
| **جدول عملاء واحد** للأطباء والصيدليات | `Customer` + `CustomerType` | البوت القديم كرّر كل مسار مرتين — أي تعديل كان يتطلب تعديلين |
| **لقطة مجمّدة** لكل زيارة | 15 حقل `snap_*` في `Visit` | إذا انتقل طبيب لمنطقة أخرى، تقرير الشهر الماضي يجب ألا يتغيّر |
| **القائمة بتاريخ** | `CustomerAssignment` | حين ينتقل عميل بين مندوبين، لا تُنسب زياراته القديمة للجديد |
| **عدة منتجات لكل زيارة** | `VisitProduct` | المندوبون كانوا يكتبون `"sleep aid , sleep well"` في حقل واحد |
| **لا تعديل بعد الحفظ** | `isLocked` + `CorrectionRequest` | نزاهة البيانات — التصحيح بموافقة المدير، والأصل محفوظ |
| **حذف ناعم فقط** | `deletedAt` في كل جدول تشغيلي | لا شيء يختفي، حتى بيد الأدمن |
| **استيراد قابل للتراجع** | `ImportBatch` | دفعة خاطئة تُلغى بضغطة بدل أن تعلق في نظام لا يسمح بالتعديل |
| **بحث عربي متسامح** | `normalizedName` + `pg_trgm` | «أحمد» تجد «احمد» — بدونه تتكرّر أسماء الأطباء بلا نهاية |

## التشغيل محلياً

```bash
# 1) قاعدة البيانات
docker compose -f infra/docker-compose.dev.yml up -d

# 2) الإعدادات
cp .env.example .env        # ثم غيّر JWT_SECRET و POSTGRES_PASSWORD

# 3) الجداول
cd apps/api && npm run prisma:migrate

# 4) بناء قائمة المستخدمين من Excel  (من جذر المشروع)
node scripts/import/build-users.mjs
#    ← يُخرج data/output/users-review.xlsx للمراجعة قبل الاستيراد

# 5) الزرع: القوائم + المنتجات + المستخدمون
cd apps/api && npm run prisma:seed

# 6) تشغيل الـ API
npm run start:dev           # http://localhost:3001/api/docs
```

بلا مستخدمين: `SEED_USERS=0 npm run prisma:seed`

## المصادقة

- اسم المستخدم = `<UserID>@dawaa-alhayat` — **ويعمل بالرقم وحده أيضاً**
- كلمة المرور الأولى = `UserID` (استمرارية مع البوت القديم)
- `bcrypt` بـ 12 جولة · قفل بعد 5 محاولات · توكن تجديد يُدوَّر عند كل استخدام
- تغيير كلمة المرور يُنهي كل الجلسات على كل الأجهزة
- المستخدم يُعاد تحميله من قاعدة البيانات في كل طلب — سحب صلاحية يسري فوراً

### الأدوار

| الدور | النطاق |
|---|---|
| `super_admin` | كل شيء — يتجاوز فحص الأذونات كلياً |
| `admin` | كل شيء عدا إعدادات النظام |
| `manager` | فريقه بأي عمق + الموافقات + التارغيت |
| `team_leader` | فريقه المباشر + الموافقات |
| `representative` | زياراته وقائمته فقط |
| `viewer` | قراءة فقط |

**37 إذناً دقيقاً**، وكل مستخدم يقبل استثناءات فردية (`UserPermission`) تمنح أو
تسحب إذناً بعينه دون تغيير دوره.

الهرم الإداري يُستعلَم بـ CTE تكرارية — المدير يرى فريقه وفريق فريقه تلقائياً.

## سكربتات مساعدة

```bash
node scripts/import/build-users.mjs          # Excel → users.json + ملف مراجعة
node scripts/check-product-aliases.mjs FILE  # قياس تغطية أسماء المنتجات البديلة
```

```bash
node scripts/e2e-smoke.mjs                   # اختبار تدفق كامل على API حيّ
```

`check-product-aliases` قيست على 16,737 إشارة منتج من بيانات البوت القديم:
**95.6% تغطية** بعد استبعاد الضجيج.

`e2e-smoke` يغطي 72 حالة: المصادقة · الصلاحيات · البحث المتسامح ·
اللقطة المجمّدة · التحقق من الإدخال · إنشاء العميل التلقائي ·
التقارير الـ11 · تصدير Excel · طلبات التصحيح.

### ملاحظة على البناء
`tsc` يستخدم `tsconfig.tsbuildinfo` للبناء التزايدي. إن حذفت `dist/`
يدوياً فاحذف الملف معه، وإلا ظنّ المترجم أن العمل منجز ولم يُخرج شيئاً.
